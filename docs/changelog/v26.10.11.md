# v26.10.11 详细更新日志

> 对比版本：v26.6.9（2026-06-09）→ v26.10.11（2026-10-11）
>
> 这一版是针对上一版的全新重构：新增「定时关机」与「守护天数」，程序从“同步完就退出”改为常驻托盘；同时重做了设置界面、更新链路和退出流程，修掉一批长期存在的问题。

---

## 一、新增功能

### 1. 定时关机

- 最多可设 **5 个时间点**，每个时间点可设为「每天」或指定星期几（周一至周日多选）。
- 关机前 **5 分钟**弹出提醒框，按钮为「本次不关机」「确认」；不点任何按钮，到点也会照常关机。
- 到点**立即执行**（系统倒计时 0 秒），不再叠加 Windows 自己的 5 分钟关机倒计时和系统提示框。
- 点右上角 **×** 或按 **Esc**，等同于「本次不关机」；下一个命中日仍会正常提醒。
- 在提醒窗口内重启程序，会补弹一次提醒，关机时刻顺延为「现在 + 5 分钟」，同一次关机只执行一次。
- 点过「本次不关机」后，程序会记住这一次，不会在剩余提醒窗口里反复弹框。
- 系统关机/注销时，提醒框被系统关闭**不会**触发“撤销关机”，不会把老师手动发起的关机取消掉。
- 关机命令通过 `%SystemRoot%\System32\shutdown.exe` 绝对路径执行，避免 PATH 中同名程序导致 `0xc0000142`。
- 程序退出后关机时间点不再生效，退出前会明确提示当前配置了几条。

### 2. 守护天数

- 窗口上半屏显示「已守护本电脑 x 天」，从第一次运行起算；**首次运行当天为第 0 天**，跨过午夜才 +1。
- 起始日期只在**时间同步成功之后**记录和刷新。启动时显示上一次确认过的值；全新安装且从未同步时显示「正在确认守护天数…」，不编造数字。
- 旧记录若早于功能上线日（2026-10-10）或晚于今天，会被判定为不可信并重置为当天，日志写明判定原因。
- 起始日期存于 `HKCU\Software\TimeSyncTool` 的 `FirstRunDate`（`yyyy-MM-dd`），可直接查看或修改。

### 3. 常驻托盘

- 同步完成后不再退出，自动隐藏到托盘，继续守候关机时间点。
- 点窗口右上角 × 只缩到托盘；托盘图标双击可恢复窗口。
- 托盘右键菜单：**显示窗口 / 立即同步时间 / 退出程序**。
- 真正退出只有两条路：菜单「选项 → 退出」、托盘「退出程序」。

### 4. 启动时自动执行（新开关）

- 设置里新增「程序启动时自动开始执行既定任务」。
- 默认**不勾**：启动后停在「已就绪，点击开始执行」，不会自己跑。
- 从 v26.6.9 及更早版本升级的机器会**自动勾上**，保持原来的使用习惯；全新安装保持不勾。日志会写明判定原因。

### 5. 设置界面

- 重做为两个分区：**常规选项** + **定时关机**。
- 关机区支持「添加时间点」「删除末行」；每行包含时间输入、「每天」开关和七个星期按钮。
- 上限 5 条，界面与配置读取都会收敛到 5 条。

## 二、界面与交互

- 主窗口由 800×600 调整为 **900×600**：上半屏显示守护天数，下半屏显示执行日志。
- 移除同步进度条，改由状态文字与按钮的可用状态表达“正在执行”。
- 底部按钮改为按窗口宽度均分排列，两端留白；窗口固定大小、不可最大化。
- 菜单「文件」改为「选项」，「视图」改为「日志」；「退出」移入「选项」。
- 关机提醒框为全自绘对话框，按钮文字是「本次不关机」「确认」，不再使用系统 MessageBox 的「是/否」；字体与配色和主界面统一，兼容 Win7。
- 窗口标题、托盘提示、计划任务描述统一为「川中计算机协会-陈叔叔希沃优化助手」。
- 托盘气泡文案改为说明常驻用途；跳过关机、正在关机、检测到更新都有对应提示。
- 卸载确认框会列出将删除的内容；卸载完成后询问是否立即退出。

## 三、行为变更（升级前请确认）

- **同步成功不再自动退出**，改为常驻托盘。
- **同步失败不再 5 秒后关闭窗口**，改为留在界面，可点「重新同步」。
- 任务管理器「结束任务」仍会被拦截，需要退出请走菜单或托盘。
- 系统关机/注销会正常放行，不再出现「此程序正在阻止 Windows 关闭」。
- 启动不再无条件自动执行，由新增的开关控制。
- 数据目录从 `%LOCALAPPDATA%\TimeSyncTool` 改为 `%LOCALAPPDATA%\SeewoOpt`；旧目录不自动迁移，卸载时会顺带清理。
- 注册表路径 `HKCU\Software\TimeSyncTool` 与计划任务名 `TimeSyncTool` **保持不变**，老用户的设置和自启不会丢。
- 运行环境从 .NET Framework 4.7.2 升到 **4.8**。

## 四、修复

### 4.1 退出与稳定性

- 统一退出入口：退出前先等后台同步线程收尾、释放单实例互斥体、写日志结束标记。修复强制退出跳过清理导致进程残留、更新时 exe 被占用而替换失败的问题。
- 退出响应从秒级降到毫秒级：状态字段加 `volatile`，不可中断的 `Thread.Sleep` 改为可取消等待。
- 修复结束 WPS 进程时 `Process` 对象不释放造成的句柄泄漏，并等待进程真正退出。
- 修复日志收尾越过运行分段标记、互斥体释放日志跑到分段之外的问题。

### 4.2 时间同步

- NTP 响应新增三项校验：**Mode 必须为服务器应答（4）**、**Stratum 必须在 1–15**、**Leap Indicator 不能为 3**；不合格的响应直接丢弃。
- 新增 2000-01-01 ~ 2036-02-07 的绝对时间边界，且**不与本机时钟比较**，避免“用错时钟判断 NTP 时间”的循环论证。
- 每次查询连发 **2 个 UDP 包**，缓解首包丢失；不再为每个服务器白等满一个超时。
- 服务器列表改为国内源优先，前四位是 `ntp.aliyun.com`、`ntp1.aliyun.com`、`ntp.ntsc.ac.cn`、`cn.pool.ntp.org`；境外源保留作备用。
- 系统时间写入改为 `SetSystemTime` + UTC，不再写死 `+8` 小时，也不做多余时区换算；非中国时区也能得到正确时间。
- 修复重构期出现的 NTP 时间戳纪元重复减偏移、`DllImport` 缺 `EntryPoint` 导致找不到 `kernel32` 导出等问题。

### 4.3 自动更新

- GitHub Release 改用框架自带的 JSON 序列化器解析，替换正则抓取；正确处理转义、多资产、说明文本里出现 `tag_name` 等情况。
- 下载资产按扩展名筛选 `.exe`/`.msi`，排除 `.sig`/`.sha256`/`.txt` 等附属文件，不再“取第一个下载地址”。
- 版本号解析容忍 `v` 前缀与 `-beta` 等预发布后缀；解析失败记录日志并跳过，不再静默当作“已是最新”。
- 修复时钟错误导致 HTTPS 证书校验失败、更新检查被标记为“已完成”从而永久失效的问题；时间同步成功后自动重试，等待上限 60 秒。
- 更新脚本重做：路径做批处理转义、替换前备份旧 exe、复制失败自动回滚、最多重试 5 次，成功/失败都有明确标记。
- 更新失败不再写“下载失败”误导排查，改为“更新失败（第 n/3 次尝试）”。

### 4.4 设置、日志与卸载

- 设置读取不再用空 `catch` 吞异常：注册表权限异常、类型损坏、日期非法都会记录原因，并按字段回退默认值。
- 保存设置前先读回注册表再改，避免把 `FirstRunDate` 等只写一次的字段覆盖掉。
- 日志按运行分段：每次启动写分隔头与运行序号，结束写结束标记，只保留最近 5 次；被强杀时没有结束标记，一眼能看出上次是异常终止。
- 日志统一由 `LogService` 写入，格式统一到毫秒，多线程写入加锁；超长消息截断到 4000 字符。
- 卸载时先停止日志写入再删目录，删除 `SeewoOpt` 和旧版 `TimeSyncTool` 目录；用户选择“不立即退出”会自动恢复日志。
- 卸载日志如实打印实际删除的注册表路径，不再手写字面量。

### 4.5 其他

- 移除 10 个不再使用的 NuGet 包（`System.Text.Json` 及其依赖链），只保留 `TaskScheduler`。
- 启动日志新增构建标识：**BuildId、exe SHA256、文件写入时间**，便于确认“跑的是哪个 exe”。
- 清理根目录下与 `WindowsFormsApp1/` 重复的一整套项目副本（约 3,100 行死代码），只保留实际参与编译的工程。

## 五、安全加固

- 自更新增加 **RSA-3072 / PKCS#1 v1.5 / SHA-256 发布签名校验**，签名不通过拒绝安装；SHA256 降为辅助记录（它与文件来自同一个响应，无法抵御仓库被入侵）。
- 私钥只存在发布者本机，`.gitignore` 排除 `*.pem`、`*.key`、`*.pfx`、`signing/`，不入库、不上传。
- 更新脚本不再把用户路径直接拼进批处理，改为转义后写入，避免路径含 `& % !` 时语法破坏或命令注入。

## 六、内部重构与工程化（对使用无影响）

- 单窗体拆分为 **13 个服务类**：NTP、关机调度、关机执行、设置存储、日志、签名验证、Release 解析、守护天数策略、会话关闭策略、开机自启、进程清理、音量控制、构建信息。
- 命名空间统一为 `SeewoOpt`；注册表路径与计划任务名保持 `TimeSyncTool` 不变。
- 工程保持非 SDK-style 的 net48 编译；CI 在干净环境复现编译，不再依赖本机 `G:\SeewoBuild` 的参考程序集。
- 新增单元测试与探针：NTP 协议解析、时间字段、日志分段、关机调度/去重/顺延、守护天数、设置序列化，共 **200+ 项断言**；另有真实窗口消息的关机链路探针、更新链路探针、提醒框渲染工具。
- 新增 `.github/workflows/build.yml`：每次 push/PR 编译 + 跑单测 + 跑关机探针；只做校验，不发布产物。
- 新增 `tools/sync.cmd`、`build.cmd`、`publish.cmd`：源码镜像、编译、签名与公钥自检。
- 许可证由 MIT 改为 **AGPL-3.0**。
- README 补充构建方式、守护天数验证方法、关机链路探针说明。

## 七、升级须知

- v26.6.9 及更早版本可自动更新到本版本，原有设置（开机自启、静默启动、音量、结束 WPS）全部保留。
- 本版要求 **.NET Framework 4.8**；Windows 7 SP1 需自行安装 4.8 运行时。
- 首次启动会创建 `%LOCALAPPDATA%\SeewoOpt`；旧 `TimeSyncTool` 目录不会自动迁移，可手动删除，卸载时也会清理。
- 维护者：上传 Release 时**先传 exe 再传 `.sig`**；必须发成普通 Release（更新源不返回预发布）；更新源按发布时间而非版本号判定最新，测试版测完请删除或转为预发布。
