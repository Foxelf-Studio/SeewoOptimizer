# v26.10.31 详细更新日志

> 对比版本：v26.10.19（2026-10-19）→ v26.10.31（2026-10-31）
>
> 这一版不新增功能，集中修托盘与界面上的四处毛病：图标时有时无、通知重复、
> 日志区空白、更新过程看不见。

## 一、托盘图标

- **启动即驻留。** 以前图标要等「隐藏到托盘」或点 × 之后才出现，窗口开着时
  托盘里根本没有它——用户只能去任务管理器确认进程还在。现在程序一启动就挂上，
  双击回窗口，右键随时退出，与窗口显示与否无关。
- **打开窗口不再摘掉图标。** 旧版在显示主窗口时把图标设为不可见，
  窗口一关才挂回去。实机日志里有过 6 分钟的空白期：程序在跑，托盘里找不到。
- **资源管理器重启后自动补挂。** 托盘图标注册在 explorer 里，explorer 一重启
  图标全部消失、进程却毫发无伤。现在会响应系统的 `TaskbarCreated` 广播并重新注册。
- **「已驻留托盘」通知不再重复。** 静默启动时 `MinimizeToTray` 会被调用两次
  （启动隐藏 + 更新检查结束转入托盘），每次都弹一遍，于是同一条通知出现两次。
  现在一次运行只提示一次。
- 通知文案改为「守护程序将在后台持续运行。非维护人员请勿进行任何更改。」
  教室里是公用机器，原文案那句「右键可立即同步或退出」等于给所有人指路。

## 二、日志区

- **从托盘恢复窗口后不再空白。** 静默启动时日志是趁窗口隐藏时一条条写进去的，
  RichTextBox 不会为隐藏期间累积的内容自动重绘——表现为日志区整块空白、
  右侧滚动条却在底部，滚一下滚轮才刷出来。现在恢复窗口时会强制重绘并把
  光标移回末尾。内容从来没有丢过，缺的只是一次重绘。

## 三、自动更新

- **检测到新版本、下载进度会写进日志区。** 以前只有文件日志和右下角系统通知；
  教室大屏常年把通知关掉，用户盯着窗口也不知道正在更新。现在日志区会显示
  「检测到新版本 x」以及每 10% 一行的下载进度，与文件日志节奏一致。
- **修复中文路径下更新失败。** 更新脚本原来按 UTF-8 写入，而 `cmd.exe` 按系统
  ANSI（简中 Windows 是 GBK）读取，脚本里的路径会变成乱码：
  `F:\陈叔叔希沃优化助手\` 被读成 `F:\闄堝彅鍙斿笇娌冧紭鍖栧姪鎵媆`。
  于是复制与重启全部指向不存在的路径，更新静默失败，进程退出后也不再被拉起。
  现在按系统 ANSI 写入，中文目录可正常更新（已在中文路径下实测 26.10.30 → 26.10.31）。

## 四、升级须知

- 从 v26.10.19 及更早版本可自动更新到本版，原有设置（开机自启、静默启动、
  音量、结束 WPS、关机时间点、守护天数）全部保留。
- **如果程序放在含中文的目录里，从 26.10.19 升级需要手动替换一次。**
  旧版的更新脚本在中文路径下会写坏路径（本版修的是"生成脚本"这一侧，
  只有跑起来的新版才生效）。下载本版 exe 覆盖原文件即可，之后可以正常自动更新。
- 仍要求 **.NET Framework 4.8**。
- GitHub 与 Gitee 上是**同一个二进制**，签名与 SHA256 完全一致。
- 托盘图标由系统外壳管理：装在 Windows 上首次运行后，图标可能被收进
  「隐藏的图标」弹出层，需要在任务栏设置里拖出来——这是 Windows 的行为，
  不是程序没启动。
