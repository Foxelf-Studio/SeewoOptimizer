# v26.10.18 详细更新日志

> v26.10.17 → v26.10.18。本次新增了 Gitee 更新源，界面与功能范围没有变化。

## 一、自动更新

- 同时查询 **Gitee 与 GitHub**，各 15 秒超时，任一源可用即可。
- 版本高者优先，与来源无关；版本相同时优先从 Gitee 下载。
- 两个源报同一版本时，另一地址作为下载备用，主源失败自动切换。

## 二、可诊断性

- GitHub API 限流（403）单独提示，与“被墙”区分。
- Gitee 尚未发布该版本时明确说明，不再报 404。
- 两个源都不可用只记一行日志，不影响关机与时间同步。

## 三、安全

- 校验顺序改为 **PE 头 → 文件版本号 == 目标版本 → RSA 签名**。

## 四、升级须知

- v26.10.17 及更早版本可自动更新到本版，但只会走 GitHub 源，设置保留。
- 仍要求 .NET Framework 4.8。
