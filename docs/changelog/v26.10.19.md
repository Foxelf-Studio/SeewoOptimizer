# v26.10.19 详细更新日志

> 对比版本：v26.10.18（2026-10-18）→ v26.10.19（2026-10-19）
>
> 这一版有三处修正，功能范围不变。

## 自动更新

- **替换文件后会重新启动程序**，修复“更新完成后进程消失、关机守候中断”的问题。
  旧版替换完文件就退出，机器上再没有进程盯着关机时间点，当晚该关的机不会关，
  而日志里看不出异常——上一个进程写的是“正常退出，准备更新”。
- 替换失败时会先还原备份的旧版本，然后**同样重新启动**。一次失败的更新不该顺带
  让用户丢掉关机守候。
- 重启时直接进托盘，不弹窗口；如果此时已有实例在运行，新进程静默退出，不会在
  无人值守的屏幕上弹出“程序已在运行中”。

## 界面

- 设置窗口图标与主窗口统一。之前设置窗口没有设置图标，用的是 WinForms 默认的
  窗体图标，任务栏和 Alt+Tab 里看起来像两个不同的程序。
- 「自动执行结束 WPS 进程任务」默认改为**不勾选**。结束 WPS 会连带结束正在编辑的
  文档，全新安装不该默认替用户做这个决定。

## 升级须知

- **老用户不受影响**：已经保存过设置（包括 WPS 开关）的机器按注册表原值执行，
  不会被新的默认值改动。
- 只有全新安装、或清掉注册表设置后重新开始，才会看到 WPS 开关默认关闭。
- GitHub 与 Gitee 上的同名版本是**同一个二进制**，签名与 SHA256 完全一致，
  从哪个源下载都一样。
- 仍要求 .NET Framework 4.8。
