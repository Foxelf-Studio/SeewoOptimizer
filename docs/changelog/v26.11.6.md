# v26.11.6 详细更新日志

> 对比版本：v26.10.31（2026-10-31）→ v26.11.6（2026-11-06）
>
> 这一版只做一件事：删掉「结束 WPS 进程」。没有新增功能，也没有其他行为变化。

## 一、移除：结束 WPS 进程

**删掉的原因**

这个功能会在执行任务时结束 `wps` / `wpp` / `et` / `wpscloudsvr` / `ksolaunch`，
原本是为了解决「WPS 2019 卡住、课件打不开」。代价是它会连带结束老师正在编辑的
文档，未保存的内容一并消失。从 v26.10.19 起默认就不勾选，但选项本身一直留着。

现在整个功能撤掉：

- 设置窗口里的「自动执行结束 WPS 进程任务」不再存在；
- 「开始执行」的流程从「调音量 → 结束 WPS → 同步时间」变成「调音量 → 同步时间」；
- 负责结束进程的代码（`ProcessCleaner`）整份删除，程序体积小了约 2 KB。

**对老机器的影响**

旧版写入注册表的 `KillWps` 值还留在 `HKCU\Software\TimeSyncTool` 里，
但已经没有任何代码读它或写它，不会影响任何行为。要清理只能靠一次专门的迁移，
收益为零，所以没做。

## 二、升级须知

- 从 v26.10.31 及更早版本可自动更新到本版，原有设置（开机自启、静默启动、
  音量、关机时间点、守护天数、失败上报）全部保留，只有 WPS 开关消失。
- 仍要求 **.NET Framework 4.8**。
- GitHub 与 Gitee 上是**同一个二进制**，签名与 SHA256 完全一致。
- 版本号从 26.10.31 跳到 26.11.6，是因为这次是**功能移除**，不是补丁。
